Add Extension Trait to the file: {{args}}

## Step 1 — Eligibility Check (stop if any condition is false)

Read the target file. Verify ALL of the following:

- [ ] The file contains at least one `virtual_method!` block
- [ ] The struct is used as a mixin (non-zero offset) somewhere in
  `libskyrim/src/re/` — search for `=> StructName,` pattern
- [ ] The file does NOT already contain a `pub trait <StructName>Ext`

If any condition is false — **stop and report why**. Do not modify the file.

---

## Step 2 — Collect Methods (three categories)

Read the entire `impl StructName { }` block and categorize every method:

### Category A — Virtual methods (from `virtual_method!` blocks)
Extract:
- method name
- args WITHOUT the first `this: &StructName` parameter
- return type

### Category B — Safe wrapper helpers
These are `pub fn` methods in `impl StructName` that:
- wrap a Category A virtual (e.g. convert `*const c_char` → `&str`)
- have an ergonomic name (e.g. `get_name_as_str` wraps `get_full_name`)

Identify them by looking for methods that call a `virtual_method!` result
or do a null-check + cast on a raw pointer from a virtual.

### Category C — Non-virtual public helpers
Any `pub fn` in `impl StructName` that is NOT a wrapper of a virtual
and NOT generated by `virtual_method!` or `relocation_func!`.
Example: `get_num_keywords(&self) -> u32`

**If Category B wrappers do NOT exist yet — write them first (Step 3).**
**If they already exist — skip Step 3.**

---

## Step 3 — Write missing safe wrappers (if needed)

For each Category A virtual that returns a raw/unsafe type, add a safe
wrapper to `impl StructName` BEFORE writing the trait:

Common patterns:

    // Raw virtual returns *const c_char → wrapper returns &str
    #[inline]
    pub fn get_name_as_str(&self) -> &str {
        core_util::ptr_to_str(self.get_raw_name())
    }

    // Raw virtual returns *mut T (nullable) → wrapper returns Option<&T>
    #[inline]
    pub fn get_item(&self) -> Option<&ItemType> {
        unsafe { self.get_item_raw().as_ref() }
    }

Rules for wrappers:
- Name: drop the `_raw` / `_ptr` suffix or add `_as_str` / `_ref` suffix
- Always `#[inline]`
- Add `// SAFETY:` comment if using `unsafe`
- Do NOT add wrappers for methods that already return safe types (bool, u32, etc.)

---

## Step 4 — Write the Extension Trait

Append at the END of the file after all `impl` blocks.

**Include in the trait (in this order):**
1. Category B safe wrappers (preferred over raw virtuals for ergonomics)
2. Category A virtuals that have NO safe wrapper
3. Category C non-virtual public helpers

**Do NOT include in the trait:**
- Private methods
- `relocation_func!` generated methods that are not intended for child use
- Methods only meaningful on the mixin itself (internal helpers)

### Block 1 — Trait definition

    pub trait StructNameExt {
        // safe wrappers first
        fn get_name_as_str(&self) -> &str;
        // raw virtuals without wrappers
        fn do_thing(&self, arg: *const ArgType) -> bool;
        // non-virtual helpers
        fn get_count(&self) -> u32;
    }

### Block 2 — Blanket impl

    impl<T: AsRef<StructName>> StructNameExt for T {
        fn get_name_as_str(&self) -> &str {
            self.as_ref().get_name_as_str()
        }
        fn do_thing(&self, arg: *const ArgType) -> bool {
            self.as_ref().do_thing(arg)
        }
        fn get_count(&self) -> u32 {
            self.as_ref().get_count()
        }
    }

All calls follow the same pattern: `self.as_ref().method(args)` — no exceptions.
The `virtual_method!` macro handles the `this` pointer internally.

## Step 5 — Verify mod.rs re-export

Open `libskyrim/src/re/mod.rs`.

- If `pub use struct_name::*;` already present — done.
- If missing — add it after `pub mod struct_name;`.
